# 独立手机／PC 详情与播放布局

## 交付内容

- 手机与 PC 分别使用 `MobileFilmLayout` / `DesktopFilmLayout`，只挂载当前页面版本，共享资料、选集、收藏和续播逻辑。
- PC 按用户最新参考采用通栏大画面、浅色渐变、小标题、左侧播放与右侧简介信息带，下方紧凑文字选集。不再保留右侧海报卡和选集／资料双栏。
- 手机使用独立海报构图、全宽主播放动作、纵向简介与选集。横屏保留手机版播放导航。
- 两端播放导航独立实现，返回与标题处于同一 flex 行，不用固定左内边距避让。手机不挂载音量滑块和画中画工具，原有音量键盘操作仍可用。
- 图片不足时不会伪造背景或分集剧照。分集接口只有集名及播放信息，PC 使用自动换行的文字按钮，显示完整集名并标记当前集，不保留缩略图占位或翻页箭头。
- 删除本轮替换后失效的 151 条旧样式规则；已有验收脚本同步使用新的详情选择器。

## 验证

- `npm run typecheck` 通过。
- `npm test`：87 项通过。
- 隔离 Chrome：PC 1440×900、800×900，手机 390×900、320×900；两种手机再检查 844×390 横屏。
- 检查只挂载对应布局、长片名不与返回重叠、返回热区至少 48px、无页面横向溢出、收藏切换、简介展开收起、切集、全屏选集、返回详情保留刚离开的集数。
- 长剧集与缺图使用明确的隔离数据。大图构图使用 TVmaze 的《琅琊榜》真实图片，其他内容为测试数据；图片完整解码后截图。检查 PC 文字选集高度、完整集名和自动换行。
- 临时 Vite 曾返回旧模块；重启本轮创建的 5192 服务后确认返回新组件，再复验。先前的旧布局截图不作为最终验收证据。

结果与截图：`docs/development/screenshots/separate-viewing-layouts/`。

复跑使用 `scripts/verify-viewing-layouts.mjs`，通过 `PLAYWRIGHT_MODULE`、`CHROME_PATH`、`TVBOX_PREVIEW` 指定环境；`TVBOX_TEST_MEDIA` 指向本机可播放的 MP4。脚本在独立浏览器上下文拦截 API，不修改真实片库、收藏或观看记录。

## 边界

本轮未构建、提交或发布。浏览器验证使用隔离 API 和本机短片，不代表真实片库资源、网盘解析或外部资料匹配覆盖率。未验证 iOS／Android 真机及原生 WebKit 全屏。低清海报切换逻辑完成静态检查，真实来源图片质量仍取决于资料服务。

本轮无图选集修正：类型检查、87 项现有测试与四种视口的浏览器回归通过；PC 8 集示例验证完整集名、48px 级紧凑高度、无横向滚动及无翻页箭头。截图已更新。
