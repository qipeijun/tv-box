# 本机运行与首条点播链路

## 环境

Node.js 22.19 或更新版本，使用 npm 安装锁定依赖。当前验证环境为 Node.js 26.7.0、npm 11.19.0。

```sh
npm ci
```

如果默认 npm 缓存无写权限，可以使用独立缓存，不需要修改全局目录权限：

```sh
npm ci --cache /private/tmp/tv-box-npm-cache
```

## 开发

```sh
npm run dev
```

一条命令同时启动前后端，支持本机和局域网 IP 访问。Web 地址为 `http://127.0.0.1:5190`，API 为 `http://127.0.0.1:4781`，Web 通过开发代理访问 API。启动前检查并复用已有项目进程；端口被占用时不要终止其他项目。

## 局域网热更新开发

```sh
npm run dev
```

启动时自动读取本机 IPv4 地址，打印手机可访问的 `http://<本机IP>:5190`，并将这些精确地址加入 API 允许列表。前端监听所有网卡，API 仍只监听本机，通过 Vite 代理访问。电脑可使用 `http://127.0.0.1:5190`。没有局域网 IPv4 地址时仍可本机开发。原 `npm run dev:lan` 保留为相同功能的入口。

React/CSS 修改通过 Vite 热更新；后端文件修改由 Node watch 自动重启 API。无需重新构建。该模式使用 5190 和 4781，启动前应停止同项目占用这两个端口的旧服务。IP 改变后重新运行命令。

`4781` 是 API 地址；看页面使用 `5190`。生产局域网入口仍使用 `npm run start:lan`，与开发模式分开。

## 生产方式本机预览

```sh
npm run build
npm start
```

访问 `http://127.0.0.1:4781`。默认绑定本机回环地址，并校验 Host、Origin 与页面请求头。现可通过 TVBOX_HOST、TVBOX_PORT、TVBOX_ORIGINS 显式配置局域网或域名入口，见 [部署与回滚](../deployment/web-v1.md)；当前 4781 预览不会被自动重启来应用新配置。

## 操作路径

1. 打开页面即自动载入内置片库，浏览真实影片与海报。
2. 点击“播放”开始观看，或打开“查看详情”选择集数。
3. 播放页通过“选集”展开列表；常用控件包括暂停、前后 10 秒、进度、音量和全屏。
4. “片库”入口可切换来源、选择其他公共订阅，或添加并保存自己的订阅。

内置精选包含 25 个内容接口（包含备用域名，不等于 25 家独立提供方），扩展片库中的 13 个入口是其中新增部分。核验来自公开配置，记录见 source-probe-2026-10-29.json 与 source-expansion-2026-10-29.json。内置配置本身不依赖启动时从第三方下载，影片仍通过第三方接口获取。

标准 CMS 媒体默认由浏览器直连；饭太硬原生适配通过后端按需解析和同源转发，覆盖真实 HLS 清单、分片、密钥和 MP4 Range。没有转码。分享页和未知解析页不会冒充媒体直链；解析接口返回的无扩展名 HLS 依照已核实契约处理。

## 当前范围与限制

- 最小点播链路与 M3U 直播已实现；分类分页、站内搜索、观看历史与进度续播已接入；主动跨站搜索与换站找片已接入；选集、切线、失败恢复和可关闭的自动连播已完成；影片收藏已接入详情、首页和资料库；整体部署验收仍待任务 10。自定义订阅保存在本机浏览器。
- 订阅会话存于后端有界内存，最多 64 个快照、一小时有效；刷新页面或重启服务后，前端会根据本地保存的选择自动重新载入片库。
- `type: 1` 仅作为配置候选，还需要真实接口校验；已实现的 `type: 3` 同站点 Node 适配单独开放，不执行 Android Spider/JAR 或任意订阅脚本。
- 通用配置和接口只接受标准端口的公共 HTTP(S)；已核实站点的解析和媒体端口按适配契约开放，授权绑定具体 origin。逐跳与 DNS 校验仍生效，并限制请求并发、响应体和超时。
- 源可能失效或有地域、跨域和编码限制，源配置可获取不等于实际可播放。
- “映场”为当前界面暂用名，尚未作为最终品牌命名确认。

## 饭太硬订阅

内置“饭太硬”从其导航页公布的 HTTPS 区域配置入口读取，支持已核实的图片 Base64 包装、JSON 注释和必要的 ext 数据解码。2026-10-30 已接入光影、奶酪、热播的 Node 原生适配；三个站点均完成隔离 Chrome 的查找、解码、切集、定位和刷新续播。其余站点保留具体原因，详见 [逐源范围](../product/spider-source-coverage.md)。

只解析配置数据并调用受控适配，不执行 JAR 或远程脚本。后端仍由 `npm start` 启动一个 Node 服务；没有 Java、Android 或第二个常驻服务依赖。独立“公开网盘片库”的 KK 接口已完成夸克本人登录与样本观看，详见 [网盘运行与验收](cloud-drive.md)；不能将此扩大为所有旧网盘站点或平台均可播放。

## 直播入口

顶部“直播”进入独立观看页，默认公共精选包含 CGTN、CGTN Documentary、CNA Originals；中国频道列表来自 IPTV-org。直播片库支持自定义 M3U，记住上次成功的内置选择或自定义地址。M3U 列表本身由受限后端读取，媒体仍由浏览器直连。

当前点播订阅中符合 type: 0、name、url 形状的 lives 项也可在直播片库中选择。饭太硬的点播适配与直播能力分别核验；其直播入口中的原生本地代理、非标准端口、专用请求头等限制不因点播支持而自动放开。

频道分组与名称搜索可同时使用，筛选不会切断当前播放。直播没有点播进度条或时间记忆；没有 EPG 数据时不编造节目单。第三方列表中的频道不是播放可用性保证。

## 多订阅管理

“片库”进入独立页面。PC 左侧片库列表、右侧来源与编辑区并排；手机按列表、来源、编辑逐层进入，可用页面返回与浏览器返回。删除在对应订阅下方确认，不叠加弹框。

最多保存 20 个具名自定义订阅，支持添加、编辑、删除与切换，分别记住站点选择。原 URL 列表自动迁移。编辑非当前片库不会切换当前内容；取消或返回会使未完成保存失效。

手动更新保留当前有效站点；失败保留上次成功配置与读取时间。地址或来源身份改变后不沿用旧影片编号；历史中的旧详情也会经过来源校验。来源配置变更创建新服务端快照，不修改已有快照；删除或换地址时只清理本机对应来源会话。

## 分类浏览与站内搜索

首页“浏览全部”进入海报网格。PC 顶栏也提供浏览入口，分类可以展开显示并按页码跳转；手机使用双列网格、横向分类与大尺寸上一页/下一页按钮。站内搜索在当前来源内执行，不自动跨站或合并影片。

分类来自 CMS 的 class 字段；分页来自 page/pagecount/total。接口没有提供时明确说明，不编造分类、筛选项或更多页。URL 保留查询、分类与页码；进入详情、选集、播放后返回可恢复原结果、位置与海报焦点。独立打开的详情/播放链接也能返回其父级页面。

订阅响应新增稳定 revision 配置指纹，历史身份不再依赖会过期的会话 UUID；同配置在重启后具有相同指纹，配置实际改变仍会阻止旧编号跨来源使用。

## 持续预览与版本切换

本机生产预览构建保留 dist 中的旧哈希资源，避免已打开页面尚未加载的模块因构建清理而 404。懒加载或页面异常提供重新打开及返回首页入口，不清空订阅和已保存历史。首次使用本轮代码需刷新已打开的旧页面；不会自动刷新正在观看的视频。生产 HTML 使用 no-cache，哈希 JS/CSS 使用 immutable；更新与回滚需保留仍在使用的资源，具体见部署说明。

## 自动连播与结束操作

在选集区可关闭“自动下一集”，刷新后保留选择。只沿当前线路原始顺序继续；末集或紧邻下一项不可播放时停止。关闭后仍可手动播放下一集。浏览器拒绝自动播放时点击播放继续；损坏的本机设置不会静默覆盖。验证与隔离复现见 [自动连播记录](auto-next-2026-10-30.md)。

## 收藏与资料库

详情页“收藏”保存当前影片与来源，刷新后保留。顶栏“资料库”在观看记录和我的收藏之间切换，首页展示最近十二部收藏。收藏进入对应来源详情，不直接播放；跨站同名影片独立保留。卡片的移除与换站查找是独立操作。最多保存 500 部，达到上限先移除，不静默淘汰。

无法读取时保留原数据，在我的收藏里可取消或确认清空重建；写入失败显示错误并保留原收藏状态。收藏与观看记录各自存储，重建收藏不删除历史。见 [收藏验证](favorites-2026-10-30.md)。

## 生产验证

构建后执行 `npm run verify:production`：另起回环临时端口验证真实 dist、图标、入口资源缓存、健康检查、内置配置及允许/拒绝的域名请求，然后关闭测试服务。不会重启现有预览，不代替真实媒体播放或公网代理验收。部署配置与回滚见 [部署说明](../deployment/web-v1.md)。
