# 详情与观看体验优化验证记录

## 实现范围

- 详情手机使用大幅海报、渐变与悬浮返回；桌面独立使用宽幅背景与海报构图。低清和缺图降低图片占比，保留片名、播放与简介。主播放动作在简介前，续播显示真实时间点。
- 外部资料独立读取：Cinemeta 电影、TVmaze 剧集。自动匹配仅采用片名和年份一致的唯一候选；跨语言、同名版本或缺年份通过详情下方“补充评分与高清图片”确认。匹配按当前片库、站点、配置与影片身份保存，最多 100 项。
- 只增强展示资料，评分标识实际来源；保留当前片库中文简介和播放线路。外部资料失败不阻断观看；剧集背景图失败仍保留评分和演员，并显示错误提示。TVmaze 署名与许可链接保留在页面。
- 手机竖屏视频下方常驻选集，桌面与全屏选集使用侧边面板。视频与面板共用全屏容器，切集不替换容器；不承诺浏览器不支持的原生视频全屏覆盖能力。
- 线路名称与集数分组保持可见，紧凑集数网格只由页面或面板纵向滚动；当前集可在面板内定位，不自动滚走详情首屏。
- 切线仅匹配唯一同名集，匹配失败要求用户选集。切线进度为临时定位值，新媒体实际播放后才保存历史；旧进度超过新媒体时长时不跳到片尾，并保留无法恢复提示。

## 实际执行的检查

- 最新 71 项 Node 行为测试通过，包含资料身份、同名重拍、未知年份、平台/ID/请求边界、上游错误、缓存去重、评分来源和背景图部分失败，以及当前仓库已加入的播放、历史等回归测试。
- TypeScript 检查通过；PostCSS 解析整个样式文件通过。
- 使用新后端 createApp 的真实外部读取核查：Cinemeta《霸王别姬》详情与中文搜索、TVmaze“琅琊榜”详情与中文搜索，均返回 200。前者搜索有 12 个候选、后者 1 个；搜索排名不当作影片身份确认。
- Metahub《霸王别姬》实际图片读取：small 海报为 300×450、medium 为 500×750、large 为 780×1170；background/medium 为 1920×1080。服务端仅将已确认的同片 Metahub small 海报路径转换为 large，不改写其他平台地址。
- 未新增依赖；仅为读取 shadcn 文档使用临时 npm 缓存，未修改系统 npm 缓存权限。

## 浏览器实际验收（2026-10-30，用户已授权）

- 复用本机 4781 后端，启动 127.0.0.1:5190 Vite 预览。原 Chrome DevTools 连接超时后，改用 Chrome 扩展自动化通道；未更改浏览器权限设置。
- 从真实非凡站点搜索“琅琊榜”，打开 2015 年条目；经界面确认 TVmaze 的 Nirvana in Fire 2015 资料，实际显示评分、1370px 海报、1920px 背景图。返回及刷新后恢复资料匹配，保留片库中文简介。
- 桌面宽屏与 375×812 手机画面检查通过；375px 页面内容宽度为 375px。320px 播放页内容宽度仍为 320px，无页面横向溢出，主要播放控件高度 44px。
- 真实 HLS 第 01、54、53 集均实际解码为 1280×720，readyState 为 4，播放时间推进；切集后页面只保留一个 video 实例。
- 手机视频为约 375×211，下面常驻选集；31–54 分组切换与当前集高亮通过。桌面侧边选集能显示、聚焦当前末集，选择第 53 集后关闭面板。返回详情显示相应集数和真实续播时间，再次续播成功。
- 外部资料只有 1 名演员时，已补充“查看片库提供的全部主演”，实际展开保留完整中文主演列表；手机次级操作统一为一行，按钮 105×44，避免收藏与换站入口分散成多行。
- 隔离切线场景使用独立 5191 端口、合成线路列表与已核实媒体入口：约 31 秒从 A 线切到唯一同名集的 B 线后恢复并继续计时；C 线包含两条同名集时，URL 保持 B 线，视频继续播放，要求用户选集。测试结束后已关闭隔离页和 5191 服务。该场景不作为真实站点提供多线路的证据。
- 原生全屏点击被浏览器拒绝，页面显示 not granted。带 userGesture 的 CDP 原生 API 隔离检查随后被自动审批拒绝，理由为试图绕过已拒绝权限、超出常规验收授权；未执行该调用，不再采用替代方式模拟授权。原生全屏与全屏内切集仍未验收。
- 预览热更新曾未刷新编译缓存，已重启本轮启动的 Vite 并重新加载、核对实际返回源码；最新画面与回归基于重启后的版本。

## 尚未验证与运行边界

- 本轮未执行 build、未更新既有 dist 或 Tailscale 预览入口；127.0.0.1:5190 为当前源码预览，保留供用户查看。

- Cinemeta 是公开资料服务，已依据官方 SDK 文档确认调用方法；未认定其服务端开源，也未把 SDK 的 MIT 许可当作影视图片或资料的再分发许可。当前不批量归档或再分发外部资料库。
- 免费服务覆盖率、评分更新时效与人物资料完整性不作保证；电影样本目前仅返回演员姓名，不伪造演员头像。
