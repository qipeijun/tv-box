# Goal：饭太硬三个真实站点的 Node 后端兼容验证

状态：首阶段实现与验证完成（2026-10-30），结果见 [验收记录](node-source-compatibility-2026-10-30.md)。截图追加来源与网盘阶段仍待开发，不能将本阶段完成解释为饭太硬全量支持。

## 当前目标与决定

保留现有 React 与 Node 服务，在一个启动入口、一个对外地址中提供真实饭太硬站点的分类/搜索、详情、按集解析和媒体转发。三个无需账号的普通站点须通过浏览器播放、切集、拖动和刷新续播。

用户在执行中明确纠正 Java 方向，要求优先使用 Node.js；此指示覆盖早期 Java 执行器方案。旧任务书、原型、构建及 native SIGILL 失败证据保留在 `.scratch/backend-compatibility/abandoned-java-prototype/`，不再作为实施要求。不能据旧 Goal 描述恢复 Java 路线。

## 执行步骤与完成标准

1. 核对真实订阅、站点身份、接口和来源许可；不将其他 CMS 重命名充数。
2. 实现光影、奶酪、热播的受控 Node 适配；保留原站点和原集序。未知插件继续给出真实不支持原因。
3. 按当前集解析，切集和离开时取消后端请求；由主服务转发媒体，逐层改写 HLS 清单、密钥与分片，并转发 Range。私网/DNS/跳转限制不得因新增适配而失效。
4. 三个站点从真实分类或搜索进入网页详情，证明解码与时间推进、切集、拖动、刷新续播；另检查手机模拟视口和失败路径。接口 200 或媒体 URL 可读不等于播放成功。
5. 运行相关自动测试和类型检查；独立构建至 `.scratch/backend-compatibility/dist` 并执行 `verify:production -- --root`。所有证据与限制分别记录。

当前上述五步已完成，见验收记录；84 项自动测试、类型检查、独立构建与生产验证通过。原基线 71 项测试通过。桌面三个站点、390px 热播模拟视口均实播通过，未完成手机真机和多用户长期压测。
