# 直播实现与验收

## 已实现

- 独立直播页面，桌面画面旁列频道，手机画面下方浏览；内置精选、中国频道列表与自定义 M3U。
- 扩展 M3U 读取频道名称、分组、台标和相对地址。拒绝误填的视频分片清单，保留非 HLS、原生协议、私网及专用请求头的限制原因。
- TVBox lives 中已核实的 type: 0、name、url 结构接入直播片库；保留原生代理等不兼容入口说明，不执行脚本和 JAR。
- 分组与搜索叠加，不改变正在播放的频道。切台释放旧播放器，失败保留当前频道并可重试；全屏下打开频道先退出全屏并聚焦列表。
- 更新片库失败保留旧列表，错误区重试失败目标，工具栏更新仍针对上次成功片库。保存上次成功的内置选择或自定义 URL，不保存会过期的服务端订阅会话编号。
- 无点播进度条、历史定位或虚构 EPG。没有媒体代理、转码和自动规避地区限制。

## 验证证据

- 20 项 Node 测试通过；新增 5 项覆盖 M3U 结构、带逗号元信息、台标与相对地址、错误格式与 HLS 清单、请求限制、TVBox lives、直播 API 归属及错误。
- TypeScript 检查与生产构建通过，Video.js 懒加载包仍有体积提示。
- Chrome 桌面 CGTN：readyState 4，1280×720，时间推进至 43 秒以上；切 CGTN Documentary 后同样 1280×720，时间超过 30 秒，DOM 中仅一个 video。
- 375×812 手机模拟视口 CGTN：readyState 4，640×360，时间超过 45 秒；页面 scrollWidth 与 innerWidth 同为 375。模拟视口不代表手机真机验收。
- 原生全屏根为 cinema-player；点击“频道”后 fullscreenElement 清空、频道标题取得焦点。
- 选择纪实分组并搜索 CNA，列表只保留 CNA Originals，当前 CGTN 未被改变。
- 使用真实中国频道 M3U 完成浏览器自定义导入：511 项，207 项明确不支持，其余为可识别 HLS 候选，不代表全部已播放。
- 隔离浏览器验收页只拦截指定验收地址：B 首次返回 502，原 A 频道和三项列表保留；点击错误区重试后 B 请求计数为 2，加载成功，错误清空。此场景仅证明交互恢复，不作为真实源播放证据。验收临时设置与请求拦截已清理。
