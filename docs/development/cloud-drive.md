# 网盘运行与本轮验收

日期：2026-10-30。现有单 Node 服务内实现，不增加 Java、Android 或第二个常驻服务。本机不运行转码器；夸克播放请求使用平台实际提供的转码地址，是否有权限及能否解码须用本人账号验证。

## 页面入口

顶部“网盘”或夸克播放失败页的“网盘登录”打开扫码面板。选择“生成登录二维码”，由本人夸克 App 扫码确认。二维码在后端本地生成，不调用外部二维码图片服务；浏览器只得到本次二维码和状态。关闭面板取消本次扫码并停止轮询，刷新二维码会撤销上一会话。

“公开网盘片库”使用 KK 当前公共 API，可分类、搜索和展开夸克分享文件；此来源独立登记，未证明与旧 `csp_KkSsGuard` 相同。其他分享平台准确提示未接入。原文件名与顺序保留，目录变化导致所选文件身份变化时返回 409，要求重新选择，避免悄悄播放别的文件。

登录后重试当前集。媒体失效时点击播放器“重试”，会重新向后端获取地址并保留当前进度，不重复使用失效直链。

## 凭据与服务重启

`TVBOX_DATA_DIR` 指定后端私有目录，默认启动工作目录下 `.tvbox-data`，已加入 Git 忽略。目录权限 0700，账号文件 0600，通过临时文件原子替换。服务重启保留同一路径即可恢复登录；验收实例使用独立目录，不能复用家庭服务凭据。

Cookie、扫码票据、分享访问令牌不会通过账号状态或播放 API 返回浏览器。Cookie 只在后端发往核实的夸克账号接口及平台返回的 HTTPS 媒体精确来源；媒体重定向或清单引用其他来源时不会继承 Cookie。账号退出后，所有关联媒体及 HLS 子资源撤销，在途媒体连接也会停止。取消扫码或退出后迟到的响应不能重新保存旧登录。

保存登录不保证平台授权永久有效。过期、会员、容量和平台限制按实际接口错误显示；不会使用公开快照里归属不明的第三方凭据。

## 临时转存和清理

已核实的网页转码路径先将所选文件转存到新建随机名称的“映场临时观看”目录。每次只提交一个所选文件，不复制整份分享；记录平台返回的任务编号和转存后的文件编号。断开页面后仍登记已提交任务，重试继续查询，不重复提交。提交结果不明时停止写入并提示人工核对，不能用自动重试制造重复文件。

同一次目录读取返回的 `stoken` 与 `share_fid_token` 必须配对用于转存，不能读完目录后重新获取分享令牌。平台明确返回非零业务错误时记录为失败；网络断开、非 JSON 拒绝页等结果不明的提交继续保留未确认状态。

只清理已完成任务确认创建、最后使用超过 61 分钟的文件。媒体资源活动期为 60 分钟，每个请求都会续期并保护相应临时文件；同一账号的转存与清理串行，家庭其他设备观看中的文件不清理。服务每 15 分钟检查，也可在面板手动清理闲置文件。只按记录中的文件编号删除，不按同名目录推测所有权，不清空目录，不删除原有文件，不触发付费。

退出会删除本地凭据并撤销媒体授权。仍在活动期内的文件和未完成任务不会被强行删除；若还有这些条目，页面明确提示用户检查自己的“映场临时观看”目录。退出后应用无凭据，不能继续清理。清理失败保留记录，返回实际错误；目录创建或任务提交结果不明时也不会擅自认领、删除未知条目。
