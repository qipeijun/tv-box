# 领域文档

本项目采用 single-context 布局。

## 探索代码前

读取 `docs/GLOSSARY.md` 以及 `docs/adr/` 中与当前任务相关的决策记录。

文件不存在时直接继续，不要求提前创建。
由 domain-modeling 技能在术语或决策得到确认后按需创建。

## 术语使用

任务标题、方案、假设和测试名称应使用术语表定义的词汇，
避免使用术语表明确排除的同义词。

缺少术语时，先判断是否引入了项目未使用的概念；
确有缺口则留待 domain-modeling 处理。

## 决策冲突

方案与已有 ADR 冲突时，明确指出对应 ADR 及重新讨论的理由，
不静默覆盖已有决策。
