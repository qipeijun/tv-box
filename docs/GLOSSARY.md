# 影视订阅与播放

本项目提供点播与直播观看能力。以下术语用于区分用户所说的不同“源”。

## 领域术语

**点播**：用户选择影片和集数后观看指定内容。

**直播**：用户选择频道后观看其当前播出的内容。

**播放线路**：同一站点内，某部影片提供的一组可选播放入口。
避免：不加区分地统称为“源”。

**切换线路**：在当前影片内选择另一条播放线路。

**换站找片**：切换内容站点并重新查找目标影片。

**换源**：切换线路与换站找片的统称；需求与验收中须明确具体指哪一种操作。

**订阅**：一份描述内容站点及其入口的配置，用户可使用内置订阅或添加自己的地址。

**内置片库**：应用提供的默认内容入口；配置和接口的核验结果不等同于所有影片始终可播放。

**网盘资源**：站点提供的、存放于第三方网盘的影片或集数，可能需要相应网盘账号登录后才能解析和观看。站点搜索结果可见不代表该资源已具备播放条件。

**网盘分享**：通过第三方网盘分享链接及可能的提取码提供的资源入口；能读取分享目录不代表已获得该资源的播放地址。

**分享转存**：将他人分享的资源保存到自己的网盘中。它属于云端文件写入，与读取分享目录、扫码登录是不同的操作，不从登录授权中推定转存或删除授权。

**分享访问令牌**：平台授予本次分享目录访问的临时凭据，夸克对应 `stoken`；不同于账号登录 Cookie。转存时需沿用获取文件令牌的同一次分享会话。

**文件转存令牌**：平台在分享目录中返回、用于转存特定文件的临时凭据，夸克对应 `share_fid_token`。它与该次分享访问令牌配对，不能混用其他会话的令牌，也不能作为媒体地址。

**网盘登录**：用户授权应用使用某一第三方网盘账号访问所需资源的过程；不等同于本应用的用户账号，也不默认代表不同设备或使用者共用该授权。

**家庭共享网盘登录**：同一家庭服务的电脑和手机共用各网盘平台的一份登录授权；可访问该服务的设备可使用该授权播放资源。

**影片资料**：描述作品本身的评分、图片、上映信息与演职员等内容；不代表当前片库提供相同版本或可播放入口。

**资料匹配**：确认当前影片与外部资料指向同一作品；同名、重拍和不同年份的作品不能直接视为同一影片。

**评分来源**：实际提供评分的平台。不同平台的评分分别标识，不能把其他平台的评分称为豆瓣评分。

**主动跨站搜索**：由用户明确发起，在当前订阅内并发查找兼容且允许搜索的站点，结果保留来源，由用户确认影片与集数。搜索能力与本次连通、结果准确性分别表达，不将同名影片视为同一身份。
