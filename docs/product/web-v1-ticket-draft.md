# Web 首版任务拆分草案

状态：已获用户确认，10 项任务已分别发布至本地 Markdown 跟踪器；本文件保留为拆分总览，当前已开始任务 01，其余任务尚未开始。

每张任务包含完成用户行为必需的界面、数据接入与对应验证；不按前端、后端、测试横向拆分。没有既有业务代码，无需单独前置重构。

| 编号 | 任务 | 阻塞于 | 可独立验收的交付 |
| --- | --- | --- | --- |
| 01 | 从真实订阅播放第一集 | 无 | 本机运行最小 Web 与轻量后端，输入真实订阅，识别一个支持站点，展示最小内容入口、影片与集数，并播放一集；不支持站点说明原因。同步建立设计令牌与基础页面。 |
| 02 | 从订阅收看直播并切台 | 01 | 使用订阅入口读取已验证直播结构或 M3U，显示分组、频道与搜索，完成播放、切台及失败重试。 |
| 03 | 管理多个订阅与手动更新 | 01 | 添加、编辑、删除与切换订阅；刷新页面后保留配置，更新失败保留旧数据与时间，不混入别的订阅结果。 |
| 04 | 浏览分类与站内搜索找片 | 01 | 分类与分页海报、站内搜索、完整详情到选集播放；返回时保持查询与浏览上下文，覆盖长标题、缺图及无横幅。 |
| 05 | 跨站搜索与换站找片 | 04 | 主动搜索当前订阅内的支持站点，分来源呈现结果；部分站点失败仍能查看已返回结果，由用户确认影片与集数后播放。 |
| 06 | 选集、切线路与播放失败恢复 | 01 | 切集、同名集匹配、匹配不确定时手选、尝试进度定位；失败保留当前选择，重试或切线路，不自动跨站播放。 |
| 07 | 观看历史与继续观看 | 06 | 保存当前浏览器的影片、来源、集数和进度，刷新后可继续观看或移除记录，来源失效时保留上下文。 |
| 08 | 可关闭的自动下一集 | 06 | 当前集结束后按当前线路集序播放下一集，可关闭并保留偏好；末集结束停止，切片或错误时不误触发连播。 |
| 09 | 收藏影片与返回播放 | 04 | 在详情收藏或取消收藏，从本地收藏列表返回对应来源影片并播放；保留站点归属，明确空态和失效来源。 |
| 10 | 完整观看路径与部署验收 | 02、03、05、07、08、09 | 整合全部已确认入口，在桌面与手机验证浏览、搜索、点播、直播、换源和本地记录；提供可复现运行部署说明及实际兼容清单。 |

## 依赖说明

01 只贯通一个站点的一集，不承载完整分类搜索、多订阅、全部播放器控制或最终视觉细节，控制首张任务规模。后续任务复用它已建立的订阅接入、播放器和页面基础。

02 与 03 不互相依赖；跨站搜索不依赖多订阅管理；历史和自动连播不互相依赖；收藏不依赖历史。06 中的换站入口在 05 完成后统一接通，相关跨功能行为由 10 验收。

每张任务都执行相关行为测试与静态检查，并在需要时记录真实播放证据；10 不替代各任务自身验证。真实浏览器或真机验证仍需用户授权。

## 发布方式

每项已单独发布到本地 Markdown 跟踪器，以编号与标题记录阻塞关系，并补充具体验收条件。本总览不是合并后的任务执行文件。
