# 剩余来源接入：任务拆分草案

日期：2026-10-30。状态：用户已确认拆分并授权继续实施；16 项任务已发布到本地任务目录。任务发布不代表来源已支持。既有首阶段实现、84 项测试和三个真实站点验收保留，原三张粗粒度待办不关闭、不改写。

## 已确认约束

- 继续现有单个 Node 后端；尽可能在后端解析，前端负责选择、登录交互和播放。公开来源自行核对，截图作为参考，不等待用户提供订阅。
- 不恢复 Java/Android 路线，不要求用户维护第二个常驻服务；保留家庭服务和原构建目录，复用已有隔离实例及浏览器验证授权。
- 已确认每个平台在家庭后端保存一份登录，电脑和手机共享；本人扫码。凭据不返回浏览器或日志，退出必须使旧播放授权失效。
- 每个来源独立核实身份、原集序和真实接口，不以同名替换，不把接口成功、目录可见或登录成功视为实播成功。
- 上游失效或平台条件不足时记录明确阻塞，继续其他不依赖它的任务；不能将失效来源的研究结果标记为播放功能完成。
- 先处理有明确参考的普通在线站点；网盘目录和分享识别可独立推进。实际平台由真实分享结果确定，不预设所有站点都属于夸克、UC 或阿里。

## 每张实施票的验收标准

- 普通点播票：当前真实订阅/站点的分类或搜索、详情与原选集、播放解析、浏览器解码和时间推进、切集、拖动、刷新续播；相关测试与类型检查通过。确实关闭搜索的来源保留分类入口，不虚构搜索能力。
- 预告片/直播票：分别验收真实预告片或正在播出的频道。直播无需点播续播，但需验证切台、停止后资源释放、离开时取消、离线或限流提示。
- 目录/分享票：真实内容、分享平台、目录/选集身份与登录条件可在页面核对。其完成不等于播放票完成。
- 网盘播放票：除点播标准外，还需凭据持久化、过期与退出、旧媒体授权失效、链接刷新、平台限流及家庭两路播放或明确限制的证据。模拟视口与真机证据分别表达。
- 所有票均贯通必要的模型、后端、页面和验证；只在真实站点需要时补充公共能力，不先建立大而全的规则引擎或纯基础设施票。

## 事实核查结果

当前接口仅分发 CMS 和热播；新增站点的最小分发可随第一张站点票引入。立播所需完整响应、逐跳 Cookie 和验证正文放入立播票，不让无状态站点等待它。糯米默认参考使用非标准端口；按核实后的具体 origin 开放，保留公网、DNS 和跳转校验。荐影的路径型编号在站点边界转换，不能开放任意 URL 代理。

固定 JS 参考仍含同步宿主请求、assets 存储和原生帮助函数，不能直接 import 当作 Node 模块。文采 JpysGuard 与本地 WenCai/文才尚未证明等价，原创、苹果、白白、小熊也尚无本地对应参考。已有源名单只是事实起点，不是存活或播放证据。

当前三个网盘源尚未解析出真实分享，所需平台集合未知。已有 Node 媒体代理可复用，但目前没有账号版本绑定、退出撤销及过期直链刷新；这些须由网盘纵向闭环实际补齐。原插件要求的夸克 mobile ticket 不自动成为 Node 自有适配的要求。

## 尚需明确的操作边界

优先验证不转存的分享播放方式。已经找到的夸克候选模块采用“保存到自己的临时目录，再取直链”的流程，涉及建目录、云端写入和容量；自动清理还涉及删除。该事实不证明所有夸克 API 或其他平台都必须转存。

用户已在本轮明确授权：若核实播放必须先转存，允许仅在应用专用目录转存所选集，并清理本应用创建且不再使用的临时文件。优先直接播放，不涉及用户原有文件或付费。详见 ADR 0007；该授权不要求所有平台都使用转存。
