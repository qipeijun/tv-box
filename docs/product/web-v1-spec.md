# Web 首版规格

状态：需求、设计方向与 10 项任务拆分已获用户确认；任务已发布至本地 Markdown 跟踪器，任务 01 基本点播闭环、02 直播链路、03 多订阅管理、04 分类分页站内搜索、05 主动跨站搜索、06 选集切线恢复、07 历史恢复集成、08 可关闭的自动下一集与 09 收藏已通过对应浏览器验收；内置片库与媒体应用重设计已接入，其他任务继续按实际完成范围推进。

## 目标与范围

个人/家庭使用的电脑优先响应式 Web 播放器，提供订阅、标准接口点播、M3U 直播、站内与跨站搜索、选集、切线路、换站找片、收藏与观看历史。

首版采用轻量后端协助源请求。原生安卓 TV、Apple TV、macOS 与 iOS 为未来可能的平台，本轮不实现。首版不执行 Android Spider/JAR，不做账号或跨设备同步；收藏与历史保存在当前浏览器。

## 订阅

- 新增已确认要求：默认内置经过核验的公开订阅，首次打开直接呈现内容，同时保留自定义添加。

- 支持添加、编辑、删除多个订阅，日常浏览选择其中一个。
- 手动更新，不后台定时刷新；更新失败保留上次成功数据，明确展示失败与数据时间。
- 支持经过真实样本核验的标准点播接口及 M3U 直播；配置解析成功与站点可播放分别表达。
- 不支持的站点保留可理解的原因，不尝试执行来源不明的 Android JAR。

## 点播与搜索

- 选择当前订阅的站点，浏览分类、内容列表和详情，选择线路与集数播放。
- 支持当前站点搜索，以及用户主动发起的跨站搜索。
- 跨站搜索默认范围为当前订阅中的已支持且允许搜索的站点，结果保留站点归属，不合并同名影片。
- 换站找片后由用户确认目标影片和集数，不假定站点间编号或集数相同。

## 播放

- 支持选集、切换线路、进度记忆与继续观看。
- 切换线路优先匹配同名集数；匹配不确定时让用户选集，不默认播放首集。
- 切线路可尝试恢复时间，但不同片源时间轴可能不一致；不能保证无缝切换。
- 支持自动下一集且可关闭，偏好保存在本机；严格按当前线路原始集序推进，末集不循环，下一项不可播放时停止并说明，不跳过或跨线。
- 自动播放被拒绝时保留下一集选择，等待点击播放；关闭连播仍可手动下一集。
- 播放失败保留当前选择，提供重试、切线路、换站找片，不自动跨站播放。
- 播放器基于真实样本选择开源实现，不自建解码器。首次播放遵守浏览器用户手势要求。

## 直播与本地记录

- 读取 M3U 频道名称、分组与可用台标，支持分组浏览、频道搜索与切台。
- 未获取 EPG 时不虚构节目单；不把点播进度恢复应用到直播。
- 影片收藏与观看历史按站点身份保存；跨站同名影片仍为独立记录。
- 记录保留来源信息；来源失效时保留记录并提供带原片名的主动跨站搜索，用户重新确认影片和集数。
- 收藏在详情操作，首页与资料库可访问；移除与打开分别操作，刷新保留，不自动播放。最多 500 部，不扩展频道收藏。读写失败明确说明，不假装保存成功；重建须在页内确认且不影响观看历史。

## 设计依据

执行 [Web 观影设计语言](../design/web-design-language.md)：夜幕蓝灰、内容优先、统一令牌、观看条与响应式选集布局。基础交互优先使用开源组件，shadcn/ui 为候选；缺图、长标题与无横幅状态均须可用。

## 技术边界与验证

- 先用一条真实点播与一条直播贯通链路，再扩展兼容范围。
- 后端请求代理不等于媒体转码或 Spider 运行环境。源适配依据配置与接口实测，不增加猜测字段。
- 直连或代理媒体按实际限制确定；需要代理 HLS 时核对清单、分片、相对路径、密钥和 Range，不只代理入口文件。
- 后端限制请求目标与重定向，不作为任意网络代理；首版本机运行与可复现部署需有说明。
- 每项交付区分静态检查、行为测试与真实浏览器播放；浏览器验证须有明确授权，未取得前记录待验证，不声称完成。
- 不默认构建或启动开发服务；需要时遵循项目协作规则。

## PC 与手机交互约束（2026-10-29 补充）

PC 与手机分别设计操作方式，不能仅将桌面弹框缩窄。片库管理采用独立页面：PC 列表与工作区并排，手机列表、来源与编辑分层进入，保留浏览器返回语义。删除在当前订阅行内确认；离开编辑层取消未完成保存。来源变化后，历史返回不能在新来源下读取旧影片编号。
