# Apple TV 观影体验升级规格

2026-10-30；手机与电脑 Web。本地设计与实现，不涉及发布。

## 参考与转译

实际取得 Apple 官方《Find things to watch》正文：https://support.apple.com/en-mide/guide/tvapp/atvbb35c9fc3/web 。参考其稳定区域导航、搜索进入内容、影片页提供播放／收藏／具体集数的组织方式。

官方《Control playback》：https://support.apple.com/en-hk/guide/tvapp/atvb5e386e66/web 。参考点击画面显示／隐藏控件、播放暂停、前后跳转及进度控制。不同平台可用功能不同；本项目只呈现已支持能力，不引入原生专属字幕、遥控或账号能力。

Web 调整：保留浏览器历史、鼠标与键盘；手机使用紧凑顶部导航和独立详情页。使用系统字体、真实竖海报，不伪造横版剧照。短暂淡入与按压反馈直接响应状态；减少动态效果时取消位移与动画。44px 是本项目触控标准，不声称为 Apple 官方 Web 规范。

## 改动与验收

| 现状证据 | 目标行为 | 验证 |
| --- | --- | --- |
| 搜索有全局导航及重复首页／片库，状态栏默认展开 | 单套主导航；搜索框→紧凑范围→一行进度→影片；状态按需展开，来源仍显示 | 1280、390、320 截图；部分成功、空、全失败、改词 |
| 首页来源与分类先于影片；手机焦点占高 | 焦点内容先呈现，来源降低权重；缩短焦点首屏，露出片架；历史／收藏能力保留 | 首屏截图、海报与焦点行为 |
| 海报播放图标实际打开详情，片架箭头无边界 | 海报只提示详情；箭头按实际滚动范围禁用 | 首尾滚动、键盘焦点 |
| 详情纯图标返回且命名固定；手机海报占高 | 可见“返回”，深链回首页，播放回影片，保留来源上下文；手机海报与标题紧凑排布 | 各来源进入与两次返回、直接链接 |
| 播放加载与错误返回位置不同 | 常驻相同位置、尺寸的返回入口；关闭面板、退出全屏分别处理 | 加载、失败、正常、全屏 |
| 按下先 reveal，点击再反转 visible | 画面点击按按下前状态决定显隐；触摸移动不抢先唤出；控件操作不自动收起 | 实际 pointerdown/up/click 时序、鼠标及触摸 |
| 面板／页面切换连续性弱 | 只对进入与显隐做短暂反馈；不延迟业务、不用动画回调提交状态 | 连续点击、减少动态、选集不重建视频 |

## 保留契约

来源、集数映射和续播仍沿用已有业务逻辑；跨站同名影片不合并。切集替换当前播放历史，不堆叠。查询、分类、页码属于 URL，父页保留滚动与焦点。收藏、历史及设置保持原存储格式。
