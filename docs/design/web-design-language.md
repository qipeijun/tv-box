# Web 观影设计语言

状态：按 2026-10-29 用户反馈重做并实现；核心原则是“这是一个媒体应用”。Apple TV 是内容层级、详情与观看交互的参考，最终体验仍遵守 Web 平台能力。

## 核心原则

打开即浏览，选中即观看。影片和视频拥有最高视觉权重，订阅、接口、站点与线路属于支撑能力，不占据观看主路径。

首屏不得要求用户先填写 URL 或逐个选择站点。默认打开内置片库，用户仍可在次级入口管理来源和添加自己的订阅。不用模拟数据、假剧照、假评分或虚构推荐掩盖真实接入情况。

## 页面与导航

- 首页：现在观看、搜索及片库管理入口；真实影片主视觉、播放主操作、详情入口和按内容类别组织的横向海报栏。
- 主视觉：保留真实竖海报比例，以三张海报组成层次，核心影片位于前景；不把竖图强行放大裁成宣传横幅。标题与前景海报必须对应同一部影片。
- 海报栏：横向浏览、鼠标箭头、键盘焦点与触屏滚动均可操作；卡片始终展示片名，更新信息来自实际接口。
- 详情：使用独立内容页面，保留浏览位置，提供片名、简介、直接播放和选集。返回恢复浏览上下文。
- 搜索：独立聚焦输入，首版已接入当前来源的真实影片名称搜索；跨站搜索保持独立任务，不假装已有聚合能力。
- 片库管理：内置订阅、自定义订阅、当前来源切换和不支持原因收于此处。切换失败保留当前片库；不后台定时刷新。
- 播放：独立沉浸页面，画面铺满可用空间并保持比例；选集按需展开，不把影片介绍、所有线路与订阅配置常驻画面旁。

## 视觉令牌

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| background | #0C0E12 | 观看与浏览空间 |
| surface | #191C22 | 内容浮层与选集 |
| elevated | #242830 | 次级控件与片库选项 |
| foreground | #F4F6FA | 标题和核心操作 |
| muted | #A7AFBC | 元信息和说明 |
| accent | #A9C7FF | 焦点及少量当前状态 |

使用语义令牌管理颜色。播放主按钮为浅色实体，其余操作降低视觉权重；视频播放时只用低干扰的黑白半透明控件。

系统字体栈为主，标题可使用 ui-rounded 回退；不下载 Apple 专有字体。桌面主视觉标题随宽度在约 38–68px 变化，手机约 34px；分区标题 21–25px，片名与正文保持可读。时间和集数使用等宽数字。

间距基于 4px，使用 8、12、16、24、32、48 等稳定节奏。海报约 12px 圆角，详情与管理浮层约 20px；胶囊限于顶部紧凑导航，不给所有内容包一层厚重卡片。

## 播放交互

- 从详情或首页点击播放后尝试开始对应集数；浏览器拒绝自动播放时明确提供播放按钮。
- 画面上方提供返回、影片名和当前集；下方为时间、进度、播放/暂停、前后 10 秒、音量、选集，以及支持时的画中画和全屏。
- 播放中约 3 秒无操作隐藏控件；暂停、缓冲、错误或键盘聚焦控件时提供清楚反馈。隐藏的交互层退出焦点顺序。
- 鼠标移动或触屏点击唤出控件；暂停时显示居中的播放按钮。拖动进度直接定位媒体，保留细进度线与足够大的操作热区。
- 键盘：空格/K 播放暂停，左右方向键前后 10 秒，M 静音，F 全屏；非全屏状态下 Escape 返回。输入控件保留自身键盘行为。
- PC 按需展开非模态侧边选集，视频与面板并排；手机竖屏在视频下方选集，全屏按方向使用侧栏或底部面板。切集释放旧播放器，沿用当前会话音量和静音设置。
- 加载、失败、重试都依赖真实媒体事件，不能用固定延时伪装就绪。控件隐藏延时只服务观看操作，不模拟业务完成。

## 开源组件与适配

基础控件、表单与浮层使用 shadcn/ui / Radix；播放引擎使用 Video.js，媒体操作层按本规范组合。浮层管理焦点和关闭行为，避免重复实现复杂的弹层基础设施。

桌面使用宽构图与海报栏，手机将海报主视觉放到标题上方。至少检查 375px 手机与桌面视口，无页面级横向溢出；局部海报栏按设计横向滚动。弹层关闭、选集与播放控件具有足够操作区域。

遵守减少动态效果设置，避免自动轮播切走用户正在阅读的内容；不自动播放宣传片。没有历史、收藏或直播实现时，不展示无法操作的入口。

## 验证边界

已使用真实内容检查 Chrome 桌面与 375px 手机模拟视口，以及媒体解码、时间推进、切集、暂停、进度、全屏、静音保留和返回。模拟视口不代表 iOS/Android 真机或原生 Apple TV 验收。

## 详情页交互细化（2026-10-29）

详情使用独立页面，保留海报、片名、真实元信息与主播放动作的内容层级。长简介可展开，选集位于正文下方；每 30 集分组，不使用页面内嵌套滚动。电脑海报与介绍并列，手机简介和播放按钮占满内容宽度。

主播放按钮跟随所选线路与集数；切线只接受唯一同名集匹配，缺集或重名时要求用户选择，不退回第一集。返回首页恢复浏览位置与原入口焦点；从播放器返回恢复详情滚动位置，并通过路由保留当前集数。错误状态提供重新加载与更换片库。导演、主演等信息仅在源实际提供时展示。

## 片库管理的设备交互

片库是独立页面，不以通用管理弹框承载全部流程。PC 使用持续可见的列表与工作区，选择片库后可直接对照来源、更新时间和编辑字段；手机每次只聚焦列表、来源或编辑的一层。表单使用完整页面与明确保存、取消动作，触屏主要操作至少 44px，返回使用页面与浏览器历史共同支持。

删除确认在对应订阅下方展开，不连续叠加弹框。返回或取消使在途保存失效；更换片库、站点或配置快照后，旧影片历史入口回到浏览，避免编号跨源复用。

## 分类与搜索的设备交互

浏览页面以真实海报网格为主体，不复制运营平台的筛选表单。桌面显示分类层级、宽搜索框与页码跳转；手机使用双列海报、横向分类和足够大的前后翻页按钮，不把桌面页码输入硬塞进窄屏。长片名最多两行，完整名称保留在详情及无障碍名称中；没有海报时使用带片名的占位。

查询词、分类和页码属于 URL 状态。进入详情和播放保留浏览来源，返回恢复原位置及对应海报焦点；加载时不将占位内容的滚动记录误当作已浏览位置。查询、分页和分类失败可分别恢复，不自动切走当前来源。

## 连续操作与观看记录（2026-10-30）

所有联网操作允许用户离开或切换选择；等待只约束对应操作，不锁定整页。旧结果与新请求分开保存，分类、查询和页码的新结果就绪后统一提交。等待时保留旧列表与旧页码，明确提示正在读取，旧列表暂不接收点击，防止在新地址下打开旧影片；分类、搜索和全局导航继续可用。刷新失败保留已有内容并提供重试，不吞掉错误。

首页最多展示八个真实分类栏，每栏最多 16 项，另有最近更新 20 项；不将卡片出现次数当作独立影片数量。父分类无聚合内容时进入真实子分类。首页焦点区由用户控制，PC 支持按钮与左右键，手机采用原生横向滚动吸附；不自动切走正在阅读的影片。标题与海报始终同步，减少动态效果时不使用平滑滚动。

观看条保留真实片名、当前集、实际进度与来源。记录按订阅、站点和影片隔离，仅保存在本机，最多一百部。正常播放每五秒保存，暂停、退出和页面隐藏立即保存；不按每帧写入本地存储。续播先读取真实详情，唯一匹配线路与集名；配置或集数变化时进入详情要求确认，不自动播放首集。已播完当前集时，接着看优先进入同线路的下一集，末集可从头重看；播放结束的自动连播由选集区开关控制，刷新后保留偏好；严格沿当前线路原始集序推进，末集停止。关闭后提供手动下一集，无法播放的下一项明确说明，不跳过。

读取损坏数据或写入失败时明确提示，原始记录不被静默覆盖；重置使用页内二次确认。网络错误与存储错误分开，网络失败不提供清空历史作为恢复动作。

## 主动跨站搜索（2026-10-30）

搜索范围在页面内用“当前来源 / 整个片库”明确切换。结果依然以海报为主体，按实际来源区分，同名不自动合并；单结果来源并排，减少重复标题下的留白。PC 将来源进度与失败原因收于侧栏，手机使用页内折叠区，不阻挡内容。部分结果成功即可操作，单个失败不会锁定全页。

改词保留旧画面并暂时停用旧卡片，手动重新搜索逐源更新；等待期间输入、导航与返回继续可用。进入详情后要求选集，返回恢复原搜索位置与焦点。换站入口位于播放和选集之后，视觉与键盘顺序一致；首页来源不随跨站详情改变。故障验收见 [跨站记录](../development/cross-search-2026-10-30.md)。

## 播放恢复细化（2026-10-30）

缺集与重名只改变待选面板，不改变当前播放；重复名称保留条目序号。切线、重试、快速切换均保留正确身份的进度，短于旧进度的新媒体从头开始并说明原因。错误后的旧暂停/等待事件不能抹掉恢复入口。选集关闭按钮固定在面板标题区域，Escape 只关闭面板；直接打开播放链接后换集的返回目标仍是对应影片详情。验收见 [播放恢复记录](../development/playback-recovery-2026-10-30.md)。

结束状态直接在视频区域提供下一集、选集与重播，避免弹框打断。手机结束操作保持 44px 热区并避让底部控制栏；PC 选集侧栏与手机页内选集均提供同一连播偏好。自动播放被浏览器拒绝时保留当前选择，明确等待用户点击，不反复重试。每集实际开始立即更新观看记录，避免快速切集后首页仍显示上一集。

## 收藏与资料库

收藏使用 2:3 海报，观看历史使用带进度的横幅缩略图，凭内容比例区分用途。详情页以“收藏 / 已收藏”的原位反馈确认结果；成功不弹框，失败在当前操作区说明。首页提供海报横栏，资料库用“观看记录 / 我的收藏”切换；PC 多列海报，手机双列。卡片常驻独立的换站与移除操作，至少 44px，触屏不依赖悬停。打开收藏只进入真实来源详情，播放仍由用户确认；核验入口时保留页面且可取消。来源失效保留卡片，换站搜索不自动合并同名影片。

## 验收补充：操作连续性

翻页反馈位于分页操作旁，旧内容保留但不能误点；不把正在操作的分页控件一起设为 inert。失败可在原位置重试，成功后才进入新内容与标题焦点。收藏/历史移除后焦点交给相邻影片，空列表回到浏览入口。首页进入收藏再返回恢复原位置；播放中换集后返回详情必须对应刚离开的集数，并保持原有返回层级。手机操作至少 44px，极窄屏可省去装饰箭头与品牌文字，保留明确名称和可操作范围。
