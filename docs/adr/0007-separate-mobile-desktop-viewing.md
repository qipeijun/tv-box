# 手机与 PC 分别组织详情和观看界面

用户明确拒绝用一套响应式布局同时兼顾手机和 PC，要求分别设计与实现两端页面。本决策补充 ADR 0004 的内容优先原则。

详情采用独立的 MobileFilmLayout 与 DesktopFilmLayout：手机按海报、主操作、剧情与选集顺序阅读，PC 按用户最新参考采用通栏画面渐变至浅色正文、播放／简介信息带及紧凑文字选集。播放页采用独立手机导航与 PC 导航，手机常驻页内选集，PC 按需打开侧栏。共用影片数据、资料匹配、续播、切线和媒体实例逻辑。

入口通过设备显示与指针条件选择页面版本，条件仅用于选择组件；不再用断点覆盖同一详情首屏的结构。手机横屏仍属于手机版，横屏及全屏仅切换观看模式。代价是两端构图需要分别维护和验证，但不会因调整一端的布局而不断覆盖另一端。

未来修改需分别检查手机和 PC。不能将“两个尺寸没有溢出”当作两端体验完成的唯一证据。
