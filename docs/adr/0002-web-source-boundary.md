# 响应式 Web 与轻量后端的首版兼容边界

首版采用电脑优先的响应式 Web 与轻量后端，同时提供经过样本验证的标准接口点播与 M3U 直播。相比纯静态网页，后端可处理部分源的请求代理需求；相比引入 Spider 执行服务，此方案将运行环境与维护投入限制在首版观看闭环内。

首版不执行 Android Spider/JAR，对依赖它们的站点显示不支持原因。解析订阅成功不代表其中全部站点可用，代理请求也不代表所有媒体可被浏览器播放。原生端的可能性不改变此首版边界。

2026-10-30 修订：用户要求尽可能在现有 Node 后端支持 Spider 来源。已实现的同站点原生适配可开放点播，并经主服务按集解析、转发所需媒体；仍不执行任意订阅脚本或 Android JAR。当前三个饭太硬普通站点的实播结果与截图参考源的待接入范围分别记录，不再用“全部 Spider 都不可用”描述当前能力。见 [单后端决定](0006-single-backend-compatibility.md) 与 [兼容范围](../product/spider-source-coverage.md)。
