# 媒体内容优先，配置退到观看路径之外

本项目首先是媒体应用。用户明确要求参考 Apple TV 的界面、排版和播放交互，打开后应直接浏览内置片库并观看，不以订阅输入、站点配置和线路列表作为首页主内容。

采用内容首页、独立影片详情页与播放页。详情页以海报与内容连续衔接为主视觉，手机和桌面分别构图；手机竖屏播放采用上方视频、下方选集，主动全屏与横屏保留沉浸观看。内置经过核验的公开片库，同时保留自定义添加；来源管理与兼容性信息进入次级片库入口。相比配置优先的组织方式，这需要维护默认片库和真实媒体状态，但能减少开始观看前的步骤。

播放能力依照 Web 实际支持实现，不宣称等同于 Apple 原生播放栈。其他 ADR 中的源兼容边界与跨站确认规则继续有效。

2026-10-30 用户明确否定详情弹框，确认独立详情页面。该选择让浏览与了解影片拥有完整空间；代价是需要维护返回位置和加载连续性。进入详情时延续已有片名与海报，线路与集数局部加载，不等待补充资料才展示整页。
