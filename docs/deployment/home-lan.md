# 家庭局域网运行与验收 · 2026-10-30

## 当前入口

http://192.168.11.154:4781

电脑与手机使用同一个局域网地址；手机连接可互通的同一 Wi-Fi，电脑保持开机并运行服务。此地址不是公网发布，不需要域名和 HTTPS 反代才能在当前家庭网络中使用。

本机配置保存在 `.env.lan`，已被 Git 忽略；配置为：

```dotenv
NODE_ENV=production
TVBOX_HOST=192.168.11.154
TVBOX_PORT=4781
TVBOX_ORIGINS=http://192.168.11.154:4781
```

启动命令：

```sh
npm run start:lan
```

它显式读取 `.env.lan`，不改变普通 `npm start` 默认只监听回环的行为。当前服务已启动，不要重复启动；以后在终端前台启动时可用 Ctrl+C 停止。电脑休眠、关机或停止 Node 服务后，手机将无法使用；本轮没有配置开机自启。

当前局域网服务绑定具体的 192.168.11.154:4781，原本的 127.0.0.1:4781 预览也可继续使用。收藏、历史和订阅按浏览器及 origin 分开保存；从 127.0.0.1 改用局域网 IP 不会自动复制旧记录，手机也不会自动共享电脑历史。

## 地址变化与排查

- 如果路由器重新分配电脑 IP，更新 `.env.lan` 中的监听 IP 与 origin，再停止旧局域网进程并重新启动；访问地址也相应变化。
- 手机打不开时，先确认电脑服务运行、两端网络可互通、未使用隔离的访客 Wi-Fi；如系统询问 Node 网络访问权限，允许家庭网络访问。
- 页面能开但视频失败，保留影片、来源与错误信息再重试或换线/换站；第三方源的跨域、地区和编码限制仍可能存在。
