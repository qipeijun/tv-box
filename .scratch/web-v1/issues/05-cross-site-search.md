# 05: 跨站搜索与换站找片

**What to build:** 主动搜索当前订阅的已支持站点，并从保留来源的结果中确认目标影片和集数后播放。

**Blocked by:** 04: 浏览分类与站内搜索找片

**Status:** resolved

- [x] 站内搜索与跨站搜索入口可区分；跨站默认只包含当前订阅内已支持且具备搜索能力的站点。
- [x] 每条结果保留站点归属，同名影片不自动合并；部分站点失败时显示对应原因，已返回结果仍可使用。
- [x] 新查询或离开搜索后旧响应不覆盖当前结果，请求有明确并发与超时边界。
- [x] 从当前影片发起换站找片时可识别搜索对象，用户确认目标影片和集数，不自动跨站播放或猜测编号对应关系。
- [x] 覆盖部分失败、快速改词、同名不同片及选择后播放的测试与路径验证。

## Answer

已接入主动跨站搜索、逐源结果、失败重试和单源分页；并发最多三个，请求可取消且有超时边界。详情与播放器失败可发起换站找片，URL 明确保存结果来源；用户先确认影片与集数，不跨站自动播放。同名与同编号结果均按来源隔离，首页站点保持不变。

56 项测试、类型检查、生产构建和 PC/手机模拟浏览器路径通过。真实虎牙第 01 集 1920×1080 播放、正确观看记录归属、返回焦点，以及隔离的部分失败、快速改词、分页、迟到响应均已核验。另修复构建清理旧资源导致懒加载白屏的问题，保留旧资源并提供错误恢复入口。
