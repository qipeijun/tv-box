# 02: 从订阅收看直播并切台

**What to build:** 在当前订阅中读取已验证的直播入口或 M3U，按频道分组浏览或搜索，播放并切换频道。

**Blocked by:** 01: 从真实订阅播放第一集

**Status:** resolved

- [x] 真实 M3U 可解析频道名称、分组及存在的台标；缺失字段不伪造，非支持结构说明原因。
- [x] 频道列表支持分组和名称搜索，选择频道后显示当前频道及播放状态。
- [x] 切台后旧请求或播放器事件不覆盖新频道；失败保留当前频道并可重试。

- [x] 桌面与手机布局可用，记录至少一个真实频道播放与切台验证，覆盖解析及切台相关行为测试。
