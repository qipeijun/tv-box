# 06: 选集、切线路与播放失败恢复

**What to build:** 在影片内切换集数和播放线路，在匹配不确定或播放失败时保留上下文并由用户决定下一步。

**Blocked by:** 01: 从真实订阅播放第一集

**Status:** resolved

- [x] 选集与当前线路、当前集的界面状态一致；快速切换时旧媒体事件不改变新选择。
- [x] 切线路优先匹配同名集数；匹配不唯一或不存在时要求手动选集，不默认跳到首集。
- [x] 切线路可尝试定位旧进度；等待新媒体可定位后执行，不能定位或时间轴不同时保留可理解反馈，不承诺无缝切换。
- [x] 播放失败保留影片、集数与线路，支持重试和切线路，不自动跨站；换站找片由对应任务提供并在最终集成接通。
- [x] 桌面视频旁选集、手机视频下方选集；覆盖切换竞争、匹配歧义、定位失败与重试行为测试。

## Answer

选集与当前线路、分组跟随实际播放；缺集/重名保持当前视频并要求明确选集。同名切线尝试恢复原进度，失败中间线路保留待恢复位置；重试沿用最后有效秒数，旧媒体事件不能覆盖新状态。PC 按需打开非模态侧栏，手机竖屏为视频下方选集，全屏共享容器。

60 项测试、类型检查、构建以及桌面/手机模拟浏览器路径通过。真实 HLS、240 秒重试、快速切线、短媒体、44px 恢复热区、全屏、Escape 及深链返回均有证据；详见 docs/development/playback-recovery-2026-10-30.md。
