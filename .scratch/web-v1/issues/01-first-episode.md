# 01: 从真实订阅播放第一集

**What to build:** 在本机运行最小 Web 与轻量后端，输入真实订阅，进入一个已支持站点的影片，选择一集并播放，形成首条真实观看闭环。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 使用真实订阅与接口数据展示一个站点的最小内容入口、影片名称和集数，不用模拟播放代替真实接入。
- [x] 根据已核实的配置识别支持能力；依赖 Android Spider/JAR 的站点显示不支持原因，不执行其代码。
- [x] 完成一集的用户主动播放，记录样本、核验时间、请求路径与实际播放结果；请求成功不等于播放通过。
- [x] 前端与后端可本机运行；请求代理限制协议、目标地址、重定向和请求规模，不作为任意网络代理。
- [x] 建立已确认的颜色、字阶与间距令牌，桌面和手机均可完成该最小路径。
- [x] 具有相关行为测试与静态检查；浏览器播放尚未获准或受外部源阻塞时明确记录待验证，任务不虚报完成。

## 实现与验证进度

2026-10-29：最小 Web、轻量后端、源适配、影片与集数展示和开源播放器已实现。8 项 Node 测试、类型检查、生产构建和本机 HTTP 检查通过；真实订阅至影片详情 API 链路通过，HLS 主/子清单及首个分片探测通过。

真实浏览器播放、视觉布局与键盘交互尚待用户授权，因此保持 claimed；接口与媒体探测不作为实际播放完成证据。验证记录见开发文档。

## 最新验收结果

2026-10-29：获准的 Chrome 实测通过。真实影片已解码为 1920×1080，时间持续推进；桌面和 375px 手机模拟视口验证、切集、进度、全屏、暂停、返回与自定义订阅验证已完成。10 项 Node 测试、类型检查与构建通过，基本点播闭环完成。

本次同时按用户新要求完成媒体应用重设计与内置片库；后续任务中的局部能力已提前接入，但未将其整体标记完成。详见最新开发验证记录。
