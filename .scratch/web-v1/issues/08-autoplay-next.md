# 08: 可关闭的自动下一集

**What to build:** 当前集结束后按当前线路的集序继续下一集，用户可关闭自动连播并保留偏好。

**Blocked by:** 06: 选集、切线路与播放失败恢复

**Status:** resolved

- [x] 正常结束时只推进至当前线路的下一集，按返回集序处理，不以集名数字猜顺序。
- [x] 自动下一集可关闭且刷新后保留用户设置；末集结束停止，不回到首集。
- [x] 旧集结束事件、切线路、手动切集或播放错误不触发重复或错误连播。
- [x] 浏览器拒绝自动播放时保留下一集选择并提供用户点击播放，不无限重试。
