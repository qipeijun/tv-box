# 09: 收藏影片与返回播放

**What to build:** 在详情收藏影片，并从当前浏览器的收藏列表返回对应站点影片继续选集播放。

**Blocked by:** 04: 浏览分类与站内搜索找片

**Status:** resolved

- [x] 详情页可收藏和取消收藏，刷新后保留结果，不重复添加相同站点的同一影片。
- [x] 收藏列表保留来源并能进入对应详情后播放，不合并跨站同名影片。
- [x] 支持从收藏列表移除，移除操作与播放入口分开，覆盖空列表。
- [x] 来源失效保留片名和来源信息并说明原因，提供换站找片入口于集成阶段接通。
- [x] 覆盖收藏持久化、重复操作、移除与失效来源测试；首版不扩展频道收藏或账号同步。

## Answer

详情页收藏/取消收藏，首页海报横栏、资料库“我的收藏”双列/多列页面已接入。按订阅、站点、影片标识隔离，不合并同名影片；保存来源与影片快照，不保存媒体地址。收藏入口先核对真实来源、进入详情再由用户播放。移除和打开独立，触屏操作常驻；支持空态、来源失效后换站查找、损坏数据显式重建及保存失败提示。
